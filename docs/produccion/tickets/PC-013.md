# PC-013 — Retirar el chat interno completo

Prioridad: P1
Estado: Pendiente

## Encargo y criterios de aceptación

**Dependencias:** PC-000. Coordinar cambios con PC-017 y PC-018.

**Archivos:** `src/components/Chat.jsx`, `UnreadBanner.jsx`, `src/lib/store.jsx`, `src/lib/api.js`, `src/App.jsx`, `src/pages/Delivery.jsx`, `server/api.mjs`, `server/store.mjs` y estilos/referencias relacionadas.

**Trabajo:** quitar interfaz, accesos, estado global, carga de mensajes, endpoints activos, eventos SSE exclusivos, contadores, sonidos y push de chat. Retirar pruebas y documentación obsoletas, manteniendo pruebas del resto de notificaciones.

**Aceptación:** la app no muestra, consulta, envía ni escucha chat; no quedan imports o componentes muertos. Mantener WhatsApp externo, avisos de pedidos, GPS y novedades operativas independientes. El esquema nuevo no necesita tablas de chat; las tablas históricas pueden quedar inertes por compatibilidad. Purgar mensajes históricos es una operación de datos separada, no un requisito para retirar la función.

**Pruebas:** búsqueda de referencias, inspección de red y notificaciones; login, pedidos, SSE operativo y entrega siguen funcionando. No eliminar cualquier icono llamado `MessageCircle`: puede ser un enlace a WhatsApp.
